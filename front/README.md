# 🚀 Backend Lab (simple)

## 📁 Estructura

```
/back
/frontend
/docker-compose.yml
```

---

## 🐳 Docker (Redis + Kafka)

```
docker compose up --build
```

---

## 🔧 Backend (/back)

```
cd back
npm install
npm start
```

Dev:

```
npm run dev
```

Kafka workers:

```
npm run kafka
```

---

## 🎨 Frontend

```
cd frontend
npm install
npm start
```

---

## 🔥 Load testing

```
npm run load
```
